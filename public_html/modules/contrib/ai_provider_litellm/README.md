# LiteLLM AI Provider

## Introduction

This Drupal module provides an integration with [LiteLLM](https://github.com/BerriAI/litellm), a lightweight service that you can self-host that provides a unified interface for various Large Language Models (LLMs).

This module allows you to use LiteLLM as an AI Provider in your Drupal application, enabling you to leverage the power of different LLMs through a single, consistent API.

## Features

*   Provides an AI Provider plugin for LiteLLM.
*   Allows configuration of the LiteLLM API endpoint and other settings.
*   Enables seamless switching between different LLMs supported by LiteLLm.

## Requirements

*   Drupal 10.2 or later.
*   An API key to a LiteLLM service.

## Installation

1.  Install the module via Composer:
    ```bash
    composer require drupal/ai_provider_litellm
    ```
2.  Enable the module in your Drupal site.
