# Claude Configuration

## Commands to run after changes
- `composer validate` - Validate composer.json
- `composer install` - Install dependencies
- `npm run lint` - Run linting tools
- `drush cr` - Clear Drupal cache

## Project Description
This is a geographic content management system for Taranto, Italy, built with Drupal 10. It features:

- Interactive maps using Leaflet.js
- Geocoding capabilities for converting addresses to coordinates
- Media management with geolocation extraction from image EXIF data
- Multiple content types for geographic data (geoimage, geoplace, territorial reports)
- Support for complex geometry types (points, lines, polygons)
- Multilingual capabilities (Italian and English)
